# Technology radar

Each quarter we publish a short radar of AI engineering techniques, tools and practices, with one of four verdicts:

| Verdict | Meaning |
|---|---|
| **Adopt** | Proven in production. We teach it as the default. |
| **Trial** | Worth using on a real project where you can manage the risk. Taught with caveats. |
| **Assess** | Worth understanding and watching. Covered in briefings, not relied on. |
| **Hold** | Avoid for new work, or stop doing it. |

## How an item gets a verdict

We apply four questions:
1. Has it survived about six months of real use?
2. Is there production evidence (engineering write-ups, incident reports, adoption), not just demos?
3. Does it map to a real failure mode or a real decision?
4. Will what you learn transfer if this specific tool disappears?

Three or four "yes" answers can earn Adopt or Trial. Two puts an item in Assess. Fewer, and it isn't listed.

This radar reflects the program's judgment for teaching and client work. It is not a vendor ranking, and we don't accept sponsorship for placements.

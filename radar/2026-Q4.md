# Radar — 2026 Q4

*Published November 2026 · Next review: February 2027*

Dates and spec status below were checked in November 2026. Fast-moving items are dated so you can tell when they may be stale.

## Practices

| Item | Verdict | Why |
|---|---|---|
| Eval-gated releases for prompts, models and indexes | **Adopt** | Treat prompt and model changes like code changes: a regression suite must pass before merge. This catches most "nothing deployed but quality dropped" incidents caused by our own changes. |
| Pinning dated model versions; no moving aliases in production | **Adopt** | Moving aliases let a provider change your system's behaviour without a deploy. Record the resolved model version in every trace. |
| Workflows before agents | **Adopt** | If the steps are predictable, a workflow with model calls is cheaper, faster and easier to debug than an agent. Use an agent only when the steps genuinely can't be known in advance. |
| LLM-as-judge, calibrated against human labels | **Adopt** | Indispensable for open-ended outputs, but only trustworthy once you've measured its agreement with human reviewers. Recalibrate whenever the judge model or rubric changes. |
| Coding agents with review and CI gates | **Adopt** | A real productivity multiplier for FDEs. Agent-written code still needs human review plus automated security, performance and secret scanning. |
| Durable execution for long-running agents | **Trial** | Checkpointing and resumable workflows prevent duplicated side effects after crashes. Worth adopting where an agent runs for minutes or performs irreversible actions; overkill for short request/response flows. |
| Semantic caching | **Trial** | Can cut cost and latency substantially, but a "similar" question isn't always the same question. Use it only with a strict similarity threshold, per-tenant scoping and an eval for wrong cache hits. |
| Multi-agent systems ("teams", "swarms") | **Assess** | Helps for genuinely parallel, independent subtasks. Otherwise tokens multiply, errors compound and debugging gets much harder. A single agent with good tools usually wins. |
| Autonomous "self-improving" agents | **Assess** | Interesting research, little production evidence. The production-ready version is an eval-driven improvement loop with humans approving each change. |
| Multi-agent or agents as the default architecture | **Hold** | Start at the lowest rung of the solution ladder that meets the requirement. |

## Standards and protocols

| Item | Verdict | Why |
|---|---|---|
| OpenTelemetry for AI tracing | **Adopt** | The vendor-neutral way to trace retrieval, model and tool calls. |
| OpenTelemetry GenAI semantic conventions | **Trial** | Widely implemented, but as of September 2026 all `gen_ai.*` attributes are still at *Development* stability and can change between releases. Pin your instrumentation library versions. ([status summary](https://www.dash0.com/knowledge/opentelemetry-genai-semantic-conventions-explained), [conventions repo](https://github.com/open-telemetry/semantic-conventions-genai)) |
| Model Context Protocol (MCP) for tool integration | **Adopt** | The common way to connect models to tools and enterprise systems. Teach the 2026-07-28 revision: stateless requests (no session handshake), stricter authorization, and an extensions framework with a 12-month deprecation policy. ([release notes](https://blog.modelcontextprotocol.io/posts/2026-07-28/)) |
| MCP HTTP+SSE transport, server-initiated sampling, Dynamic Client Registration | **Hold** | Deprecated in the 2026-07-28 revision. Don't build new servers on them. ([release notes](https://blog.modelcontextprotocol.io/posts/2026-07-28/)) |

## Security and compliance

| Item | Verdict | Why |
|---|---|---|
| OWASP Top 10 for LLM Applications 2026 | **Adopt** | Our baseline threat checklist. Prompt injection stays at #1; excessive agency rose to #3; unbounded consumption (cost and resource exhaustion) rose sharply. ([OWASP](https://genai.owasp.org/home/resources/owasp-genai-llm-top-10-2026/), [summary](https://www.helpnetsecurity.com/2026/08/06/owasp-2026-llm-top-10-released/)) |
| OWASP Top 10 for Agentic Applications 2026 | **Adopt** | Use alongside the LLM Top 10 whenever a model has tools, memory or the ability to act. ([OWASP](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/)) |
| India's DPDP Rules, 2025 as a design requirement | **Adopt** | Notified in November 2025 with obligations phasing in over about 18 months. Design consent, notice, retention and deletion into systems for Indian clients now rather than retrofitting. Confirm current deadlines with counsel. ([PIB document](https://static.pib.gov.in/WriteReadData/specificdocs/documents/2025/nov/doc20251117695301.pdf)) |
